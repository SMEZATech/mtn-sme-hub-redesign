# MTN SME Hub Redesign

A working archive for the MTN SME Hub redesign project: the mockup site, the brand identity reference, and supporting reports.

Open `index.html` for the full archive with links to everything, or browse directly:

- `site/` — the redesigned MTN SME Hub mockup (homepage, category pages, articles, Business Solutions with a plan configurator, Events, Insights, About, Partners and Stakeholders)
- `site/brand_ci.html` — the Brand CI, the accountability reference every mockup screen is held to
- `reports/` — supporting strategy and data reports
- `brief.md` — the original project brief

## Status

This is a design mockup for client review, not a production build. Product pricing, event listings, and the partner list are illustrative where noted on the page itself, pending confirmation from MTN Business.
